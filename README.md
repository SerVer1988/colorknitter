# ColorKnitter

Помощник для плетения картин нитью в стиле String Art: генератор превращает фото
в последовательность гвоздей, а вязалка ведёт по ней шаг за шагом с голосовыми подсказками.

## Структура

```
index.html        вязалка (открывается по умолчанию)
generator.html    генератор схемы из фото
manifest.json     настройки установки на телефон (PWA)
sw.js             сервис-воркер: кеш для работы без интернета
css/
  common.css      общие стили
  knitter.css     стили вязалки
  generator.css   стили генератора
js/
  pwa.js          регистрация сервис-воркера
  knitter-boot.js запуск вязалки: редирект на генератор, разблокировка голоса
  knitter.jsx     приложение вязалки (React)
  generator.js    логика генератора
img/
  logo.png        логотип в шапке
  icon-*.png      иконки приложения
  ui/             иконки кнопок
```

## Важно

- `manifest.json` и `sw.js` должны лежать в корне.
- После любых изменений увеличьте версию `CACHE` в `sw.js`, иначе на телефоне останется старая версия.
- `js/knitter.jsx` загружается браузером через Babel, поэтому сайт нужно открывать
  через сервер (GitHub Pages), а не двойным щелчком по файлу.
