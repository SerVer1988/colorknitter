# ColorKnitter

Помощник для плетения картин нитью в стиле String Art: генератор превращает фото
в последовательность гвоздей, а вязалка ведёт по ней шаг за шагом с голосовыми подсказками.

## Структура

```
index.html        вязалка: разметка + код приложения на React
generator.html    генератор схемы из фото
manifest.json     настройки установки на телефон (PWA)
sw.js             сервис-воркер: кеш для работы без интернета
css/
  common.css      общие стили
  knitter.css     стили вязалки
  generator.css   стили генератора
js/
  pwa.js          регистрация сервис-воркера
  knitter-boot.js запуск вязалки: редирект на генератор, разблокировка голоса
  stringart-core.js ядро генератора: выбор линий, модель нити, превью
  generator.js    страница генератора: подготовка фото, фоновый расчёт
img/
  logo.png        логотип в шапке
  icon-*.png      иконки приложения
  ui/             иконки кнопок
```

## Как работает генератор

На каждом шаге нить идёт к тому гвоздю, линия к которому сильнее всего уменьшает
отличие «нитяной картинки» от фото. Картинка моделируется физически: нить закрывает
часть пикселя (толщина нити / размер пикселя рамы), нити накладываются друг на друга,
свет смешивается как у глаза на расстоянии, ошибка считается в воспринимаемой светлоте.
Генерация останавливается сама, когда новые линии уже не улучшают картинку
(или при достижении лимита линий). Одна и та же хорда не повторяется.

В цветном режиме у каждой нити свой непрерывный путь; нити идут блоками
(«интервал»), и в начале каждого блока выбирается цвет, который сейчас полезнее всего.

Режимы: «Чёрный» (одна чёрная нить), «Ч+Б» (чёрная и белая: белая высветляет
там, где стало слишком темно) и «Цвет». Генерация останавливается, когда новая линия
даёт меньше 1 % пользы первой — лишних часов плетения не будет.

Кисти на фото: «Главное» (лицо, глаза — им достаётся больше нитей) и «Фон»
(туда нити не пойдут). Пометки двигаются вместе с фото.

Настройки рамы: число гвоздей (кратно 4 — сектора A, B, C, D), диаметр, толщина нити,
цвет доски. Они влияют на результат и запоминаются. Кнопка «Шаблон рамы» скачивает
SVG в натуральную величину с подписями гвоздей для разметки.

После расчёта показываются расход нити (с запасом 10 %) и примерное время плетения.
Схему можно скачать в .txt (номер шага и гвоздь, смены нити) — вязалка умеет
загружать этот файл обратно, вместе с числом гвоздей.

Расчёт идёт в фоновом потоке, страница не зависает; кнопка «Остановить» сохраняет
то, что уже готово.

## Важно

- `manifest.json` и `sw.js` должны лежать в корне.
- Сервис-воркер берёт файлы сначала из сети, поэтому обновления видны сразу; без интернета приложение работает из кеша. Версию `CACHE` в `sw.js` увеличивайте, когда меняется список файлов.
- Код вязалки на React специально оставлен внутри `index.html`: так страница работает
  и при открытии файла напрямую. Если вынести его в отдельный файл, без сервера будет чёрный экран.
- Офлайн-режим (сервис-воркер) работает только при открытии через сайт (GitHub Pages).
